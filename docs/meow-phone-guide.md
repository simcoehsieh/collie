# Meow：附件、交接與截圖

## Codex 的 Artifacts 在哪裡？

打開 Codex 分頁 → 右上角選單 → **Artifacts**。即使這個分頁還沒有附件，入口也會顯示；
按 **所有產出／All artifacts** 可以瀏覽其他分頁或尚未對應到分頁的檔案。

Artifacts 收的是 agent **有登記的產出檔案**，不是所有改過的程式碼或每一則回答。
agent 寫好報告後可使用 `collie artifact add report.md --title "報告名稱"` 登記。
Codex 會使用自己的 thread/session id；分頁對應必須由 multiplexer 提供正確的 session 資料。
缺少對應資料時，檔案仍可在全域附件庫找到，不會猜測歸屬。

## 把 Claude 的工作交接給 Codex

1. 在 Claude 分頁選單選 **交接給另一個 agent**。
2. 選 **codex**，再選 **Codex 模型**與**推理強度（effort）**。
3. 填入希望接手的工作；可以先請 Claude 寫交接摘要，或取消勾選後立即交接。
4. 按交接按鈕，Meow 會在同工作區開新 Codex 分頁，讓它先讀交接文件。

effort 選項依模型而變；選「沿用啟動器設定」會保留原本設定。
交接傳遞的是摘要、最近對話、附件與後續指令，**不是**把 Claude 的原生 session 轉成 Codex 格式。
若主機沒有 Codex 模型目錄，仍可用啟動器預設值。帶有自訂參數或 profile 的啟動器保留它自己的設定。

## Screenshot 怎麼用？

這個功能會請 **Mac 上的瀏覽器拍網頁**。`localhost` 指的是 Mac，不是手機。

1. 在分頁選單選 **截圖並標註**。
2. 填要拍的網頁網址，例如 Mac 上開發網站的 `http://localhost:5173/`。
3. 選手機、平板或桌面尺寸；這三個按鈕是拍攝尺寸，不是瀏覽器分頁。
4. 按 **截圖**，再圈選、畫箭頭或查看元素。
5. 按 **加入訊息草稿**，描述要改的地方，確認後再送出。

`http://127.0.0.1:4318/api/snapshot` 是 Meow 的資料端點，不是要拍的網站。
現在自動建議會略過這類 API／健康檢查網址。手上已有手機截圖時，可以直接從訊息欄的迴紋針附加。

## 本次驗證範圍

模型參數在後端會核對主機目錄，並以獨立 shell 參數傳遞。測試使用假的 multiplexer 與暫存檔案，
不會為了驗證而對你的既有 agent 送訊息或啟動付費模型工作。手機與平板的瀏覽器測試另行驗證這三個入口。
